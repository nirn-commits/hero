# 超人列島クロニクル

日本を舞台に、何百人ものヒーローとヴィランが活動する1年間を自動で進めて眺める、テキスト中心のシミュレーションです。
プレイヤーの操作は「速度を選ぶ」「気になる名前をタップする」くらいで、あとは世界が勝手に動きます。

## 遊び方

- `index.html` をブラウザで開くだけで始まります（ビルド不要）。
- 上部のボタンで速度を切り替えます（一時停止／ゆっくり／標準／速い／最速／年末まで）。
- ニュースやランキングに出てくる名前をクリックすると、そのヒーロー・ヴィラン・組織・チームの詳細と活動記録が見られます。
- 12月31日に年間表彰が行われ、15秒後に自動で翌年へ進みます（表彰画面のチェックで切り替え可能）。何年でも続けられます。
- 世界はブラウザ（IndexedDB）に毎週自動保存され、ページを開き直すと続きから再開します。
- 「新しい世界」で別のシードの世界を作り直せます（同じシードなら同じ世界になります）。
- 上部の「スロット」から、3つの世界を別々に保存して切り替えられます。切り替えるときは今の世界が自動で保存されます。「新しい世界」は遊んでいるスロットを上書きします。

## 画面

- **概況**：今年の数字、都道府県のタイル地図（事件数・ヒーロー数・ヴィラン数）、トップ4の順位推移、月別の事件数、今年の大きな出来事。
- **推し**：☆で登録したヒーローを、順位・今年の成績・順位推移・最近のニュースつきのカードで一覧できます。推し全員の最新ニュースもまとめて読めます。
- **ランキング**：表彰台つきのランキング。属性ごとの紋章（炎・氷・雷…）と、1位との差を示すバー。
- **記録**：殉職・引退・スキャンダル・殿堂入り・二世・闇堕ち・改心・怪獣・組織壊滅・結婚・歴代表彰・月間1位を年ごとに一覧できます。
- **名鑑／ヴィラン／勢力図**：検索や並び替えができます。
- **ヒーローのプロフィール**：名前を押すと、異名・愛称・口ぐせ、基本データ（誕生日・血液型・身長体重・出身校・家族・スポンサー・推定年収など）、能力（必殺技・代償・弱点・能力値）、人物（座右の銘・好物・特技・コスチューム）、成績、人間関係、活動記録が見られます。
- **人生年表・ファンの声**：プロフィールに、デビューから受賞・結婚・因縁・引退までの人生年表と、支持層（子どもたち・シニア層・地元など）とファンの声が出ます。
- **口調と語録**：全員に見えない口調があります。ほとんどは丁寧語かくだけた標準語で、地元出身の人には方言が少し混じり、武士・忍者・お嬢様などのくせの強い口調は条件がそろった一部の人だけ（全32種類）と一人称があり、勝利・救助・謝罪・結婚・引退などの場面でその口調で話します。記者の取材に答えるニュースもあります。プロフィールの「語録」に最近の台詞が残ります。ヴィランも犯行時・逃走時・逮捕時に口調つきの台詞を言います。
- **引退後**：引退したヒーローの近況がときどきニュースになり、まれに現役復帰します。
- **文字サイズ**：上部の「文字」ボタンで標準・大・特大を切り替えられます。

## 世界のしくみ

- **ヒーロー** 約340名をランダム生成。名前（属性語・ご当地名物・ひらがな系など10パターン以上）、本名、出身地、前職、能力の由来、ヒーローになった動機、趣味、性格2つ、能力値7種を持ちます。
- **能力** 約170種。炎・氷・時間・空間などの属性と、戦闘／救助／捜査の得意分野、1〜5の「格」があります。「かき氷生成」「夕飯透視」のような弱い能力も混ざっています。
- **事件** 毎日5〜9件。街の小事件、救助、捜査、ヴィラン犯行、怪事件に加え、まれに大災害・怪獣襲来・組織テロ・アジトへの一斉摘発が起きます。近くにいるヒーローが出動し、能力の相性と実力で結果が決まります。
- **ヴィランと組織** 逮捕・脱獄・宿敵関係・組織への加入・首領交代・壊滅・新組織の結成。捜査進捗が100に達した組織には一斉摘発が行われます。
- **人間模様** スキャンダル（性格によって起こしやすい種類が変わる）、謹慎、芸能活動、ライバル宣言、チーム結成と解散、熱愛・結婚・破局、弟子入り、改名、移籍、引退、殉職、闇堕ち、ヴィランの改心。
- **年中行事** 新人一斉デビュー（4月）、バレンタイン、ヒーロー総選挙（7月）、台風シーズン、年末の年間表彰など。
- **ランキング** 活躍ポイント＋人気で毎日計算。ポイントは週ごとに少しずつ目減りするので、最近の活躍が順位に効きます。
- **世代交代** 年をまたぐと全員が1歳年をとり、ベテランは引退していきます。新人の数は現役人数に合わせて調整されるので、何十年続けても300〜400名程度で安定します。活躍したヒーローは引退・殉職時に殿堂入りし、数年後にその子どもが「二世ヒーロー」としてデビューすることがあります。

## 物語の仕掛け

- **宿敵の物語**：ヒーローとヴィランの因縁を戦績つきで記録します。3戦以上戦った宿敵を本人が倒すと「決着」となり、ヴィランは脱獄できない特別監獄へ送られます。殉職や引退で終わる因縁もあります。
- **黒幕の年**：数年に一度、すべての組織を束ねる黒幕が現れます。2月に影が見え、春から組織を傘下に収め、8月に予告、12月20日「審判の日」に全国の精鋭ヒーローとの最終決戦になります。負けると翌年に持ち越します。
- **成長の節目**：初検挙、通算検挙・出動・救助の大台、初の1位、活動10年・20年、連続トップ100入りなどを「節目」ニュースとして流します。
- **師弟の継承**：師匠が引退・殉職すると弟子が技を受け継ぎ、「二代目○○」を名乗ることがあります。
- **時代の流れ**：2〜5年ごとに「ヒーロー規制法の時代」「能力者バブル」「大脱獄の時代」「怪獣の時代」などが訪れ、事件・スキャンダル・新人の数などの起こりやすさが変わります。支持率が低いと暗い時代、高いと明るい時代になりやすくなります。
- **事務所の勢力争い**：事務所ごとの勢力ランキング（勢力図タブ）。毎月、引き抜き・独立・合併・倒産が起こります。
- **世論の支持率**：大事件の解決で上がり、スキャンダルや敗北で下がります。38%を下回ると制度改革（抜き打ち監査など）が行われます。
- **週刊誌の表紙**：毎週月曜日、その週いちばん話題になったヒーローが「週刊ヒーロー」の表紙を飾ります。
- **推しヒーロー**：名前の横の☆で登録。推しが関わるニュースは色つきで流れ、大きな出来事は画面の隅でお知らせします。「推しのみ」で絞り込みもできます。
- **台詞**：共闘のあとに2人がそれぞれコメントしたり、ライバルに抜かれた側が一言残したり、引退・殉職に弟子やライバルが言葉を贈ったりします。
- **全国大会**：毎年10月に上位16名のトーナメント。11月3日が決勝。勝ち上がり表は概況タブと記録タブで見られます。
- **年代記**：10年ごとに、歴代王者・時代の移り変わり・黒幕との戦い・決着した因縁・殉職者などをまとめます。進行中の10年も記録タブで読めます。

## 山場の仕掛け

- **号外**：殉職・首位交代・闇堕ち・決着・新記録・世界一などの大ニュースが起きると、進行を止めて新聞風の「号外」が出ます。再生中なら10秒後に自動で再開します。号外の画面のチェックで出さないようにもできます（2週間に1回まで）。
- **超人日報**：概況タブの一番上に、その日いちばん大きなニュースを一面記事として載せます。
- **今週の注目**：毎週月曜日、宿敵の対決・ランキング争い・記録への挑戦・一斉摘発・連続事件の行方などを予告し、週末に結果を書き込みます。
- **連続事件**：ヴィランが特定のヒーローに予告状を出し、数週間かけて事件・罠・協力者の登場を経て最終話の決戦に至ります。
- **歴代記録**：通算検挙数・救助件数・出動回数・連勝・連続1位・年間1位の回数・全国大会の優勝回数を記録タブの「歴代記録」で見られます。一定の水準を超えてから塗り替えられると【新記録】のニュースになります。連勝が伸びると途中経過も報じられ、止まったときもニュースになります。
- **関係のドラマ**：ライバル同士の毎週の順位争いの戦績、弟子が師匠を追い抜いたことによる確執と和解、チームの加入・脱退・リーダー交代・名コンビ、怪獣や大災害の現場に宿敵ヴィランが加勢する展開があります。
- **ご当地**：4・7・10月に都道府県の治安ランキングを発表します。地図の県を押すと、その県の「地元の守護者」と「ご当地の悪」が出ます。
- **海外**：海外ヒーローの来日、国際手配ヴィランの上陸、8月20日の世界大会があります。
- **予想と目標**：概況タブで毎年「年間1位・全国大会の優勝・殉職者の有無」を予想でき、年末の表彰画面で答え合わせします。推しタブでは推しごとに「トップ10入り」などの目標を立てられ、年末に達成したかがわかります。予想と目標は、このブラウザだけに保存されます。

## 記憶と因果・物語の中心人物・あらすじ

- **記憶と因果**：ヒーローは出来事を覚えています。敗れたヴィランに勝つと「○年に敗れた相手への雪辱」と報じられ、窮地を救われた相手と再び同じ現場に立つと「かつて命を救われた相手と肩を並べた」と描かれます。救助された子どもが数年後にヒーローとしてデビューし、恩人と同じ現場に立つこともあります。師匠・伴侶・ライバルが殉職すると、毎年の命日に残された人の様子がニュースになります。プロフィールの「縁と記憶」で一覧できます。
- **物語の中心人物**：強さだけでなく、さまざまなきっかけで「物語の中心人物」に選ばれます。きっかけは、4週連続1位（頂点）、正義感の強さと救助の積み重ね（正義の人）、2年越しの雪辱、宿敵との長い因縁（宿命）、師匠の技の継承、殿堂入りした親を持つ二世、恩人に救われた子ども（恩返し）、怪獣退治（救世主）、スキャンダルからの再起、元ヴィラン、40歳を過ぎてからの台頭（遅咲き）、活動25年（鉄人）、弱い能力での上位（弱い能力）、伴侶との死別（喪失）、教え子、救助と思いやり（慈愛）、炎上続きでも上位（問題児）、養成校での活躍（学園の星）など。選ばれるとニュースで紹介され、日常の場面が描かれるようになり、ニュースに◆の印がつきます。概況の「物語の中心人物」と、記録タブの「中心人物」で一覧できます。
- **連載の物語**：推しや物語の中心人物を主人公に、数話かけて進む物語が始まります（同時に3つまで）。種類は「挫折と再起」「宿敵との決着」「故郷を守る」「受け継ぐもの」「師弟」「恋と戦い」「恩返し」で、その人物の記憶や人間関係（敗れた相手・宿敵・亡き師匠・弟子・恋人・恩人）に合わせて選ばれます。2〜3週間おきに【題名　第○話】のニュースが届き、最終話は実際の事件として起こり、勝敗で結末（完結／未完のまま幕）が決まります。勝てば恋人と結婚したり、受け継いだ技が新しい必殺技になったりします。概況の「連載中の物語」から、各話を通して読めます。
- **年ごとのあらすじ**：プロフィールで、その人物の1年を季節ごとの文章で読めます。年末の表彰画面には、推しと物語の中心人物のその年のあらすじが並びます。

## 相関図・ヴィラン・画面の使いやすさ

- **ヒーロー名**：学園ものらしい名前の作り方を増やしました。名字のもじり（例：名字の読み＋能力の言葉）、当て字（例：紅蓮頼雄斗）、道具＋体の一部（例：ゼリーハンズ、パラソルガード）、職業＋動物（例：ギャングモス、キャプテンラクーン）、造語（例：ブリザニウム）、名字のあだ名（例：ヤマミン）。養成校の生徒は7割、プロのヒーローは3割がこの型の名前になります（新しく作る世界から）。
- **相関図**：ヒーロー・ヴィラン・生徒のプロフィールに相関図があります。伴侶・恋人・師弟・親子・ライバル・宿敵・命の恩人・チーム・インターン生・よく戦うヴィラン（勝敗つき）などが、味方は実線、敵は破線で描かれ、名前を押すとその人物へ移れます。
- **ヴィラン**：通り名・手口・犯行の署名・潜伏先のうわさ・好きなもの・苦手なもの・性格・懸賞金・最終目撃・ヒーローとの対戦成績・語録・経歴を持つようになりました。プロフィールは手配書の形で表示されます。自分を捕まえたヒーローを覚えていて、脱獄すると復讐を宣言し、やがて【復讐】の事件を起こします。ときどき拠点や目撃情報、懸賞金の引き上げがニュースになります。ヴィランタブには懸賞金上位の手配書が並び、検索と並び替え（危険度・懸賞金・犯行数・勝利数・新しい順）ができます。
- **画面の改善**：詳細画面に「← 戻る」、プロフィールと概況に目次、名前にマウスを乗せると簡易カード、名鑑の「推しのみ」「物語の中心人物のみ」の絞り込みを追加しました。スマホでは「文字」「スロット」「新しい世界」を「メニュー」にまとめ、ヘッダーを詰めました。

## ヒーロー養成校（学園）

- **6つの養成校**：国立英峰高校（東京）、私立天翔学園（大阪）、県立あおば救命高校（宮城）、私立白鷺学院（京都）、私立玄海ヒーロー高等専修学校（福岡）、道立北辰高校（北海道）。学校ごとに素質の高さ、教育方針（戦闘・救助・捜査）、校訓があります。教員は引退したヒーローで、引退したヒーローがあとから教員になることもあります。
- **生徒**：1学年10〜18名ほどの高校生（15〜18歳）。能力・性格・口調・夢・部活・見た目を持ち、毎月の訓練で能力値が伸びます。1年生は6月にヒーロー名を決めます。
- **1年の行事**：4月の入学式と能力測定、6月のヒーロー名発表会と全国高校ヒーロー体育祭、7月の期末実技試験、8月の林間合宿（ヴィランに襲われることがあり、生徒が連れ去られると数日後にプロヒーローが救出に向かいます）、9〜11月のインターン（実在のヒーローの事務所で研修）、10月の学園祭、11月の仮免許試験、1月のヒーロー資格試験、2月の進路決定、3月の卒業式。
- **学園生活**：親友・ライバル・片想いと交際、能力の覚醒、スランプ、けが、赤点、無許可の能力使用による処分、転校生、退学など。
- **卒業後**：資格を取り、事務所の採用枠に入った生徒だけが4月1日にプロヒーローとしてデビューします（毎年おおむね4人に1人）。インターン先の事務所に入ったり、インターン先のヒーローに弟子入りしたりすることもあります。学生時代のライバルや恋人の関係はプロになっても続きます。ヒーローにならなかった卒業生は、警察・研究者・家業・留学など別の道へ進み、ときどき近況がニュースになります。まれに遅咲きのデビューをしたり、ヴィランになったりする人もいます。
- **学園タブ**：学校ごとに、在校生の学年別一覧（校内の評価順）と卒業生の進路を見られます。生徒の名前を押すと、プロフィール・学年順位・人間関係・インターン先・学園年表が出ます。
- **推しの生徒**：生徒も☆で推しに登録でき、推しタブに並びます。推しの生徒がヒーローになると、ヒーローとしても自動で推しに加わります。
- 記録タブの「卒業と進路」「学園の出来事」で、これまでの卒業生と大きな出来事を一覧できます。

## 担任になる（教師モード）

教師モードは、新しい世界を作るときのチェック、または学園タブの「有効にする」で有効にしたときだけ使えます。有効にすると「担任」タブが現れ、好きな養成校の教師として着任できます。無効にしても担任の記録は残り、再び有効にすると続きから再開します。世界はこれまでどおり自動で進み、指導はその上に重ねて行います。着任しなければ、これまでと同じ遊び方のままです。担任タブは「クラス」「時間割」「行事と試験」「予算と設備」「教師」「日誌」に分かれています。

- **時間割**：平日5日×午前・午後の10コマに、戦闘訓練・救助訓練・捜査演習・座学・能力訓練・連携訓練・自主練・休養を入れます。月曜日ごとに1週間分の成果が出ます。型（バランス・戦闘・救助・座学と捜査・休養）から選ぶこともでき、1週間で伸びる能力値・疲労・やる気・熟練度・団結の見込みが表示されます。
- **生徒の裏の数値**：やる気（伸びの速さ）、疲労（60を超えると伸びが落ち、80を超えるとけがをしやすい）、信頼（試験・闇堕ちの防止・絆）、適性（戦闘・救助・捜査の向き不向き。面談2回か10週間で判明）、能力熟練度（50で必殺技を編み出し、100で能力が覚醒）。編み出した必殺技は、ヒーローになっても使い続けます。
- **指導ポイント**：毎週2回復し、個別指導（戦闘・救助・捜査・能力）、面談、ほめる、休ませるに使います。
- **絆**：信頼が50・70・90に届くと、その生徒の夢や能力にまつわる特別な話が起こります。
- **相談**：生徒からの悩み、喧嘩、恋愛、学費、退学、スランプ、体育祭の作戦、試験前の特訓、インターン先の推薦、3年生の進路などに3択で答えます。3週間答えないと、生徒が自分で決めます。
- **期末実技試験**：7月1日に担当の先生のタイプ（パワー型・スピード型・頭脳派）がわかり、作戦（正面突破・陽動と連携・持久戦）を選びます。7月17日に2人1組でプロの先生に挑み、相性・団結・疲労・熟練度で結果が決まります。
- **団結**：連携訓練や救助訓練で上がり、何もしないと少しずつ下がります。期末試験に効きます。
- **学級予算と設備**：毎月入る予算で、トレーニング機器・医務室の設備・資料室・実戦シミュレーター（ずっと効く）や、差し入れ・強化合宿・サポートアイテムの試作（その場で効く）を用意できます。
- **教師の成長**：授業・相談・行事で経験を積むとレベルが上がり、技能（実技指導・カウンセリング・授業設計・人脈・体力）を覚えられます。
- **評判と査定**：体育祭・試験の結果やヒーローになった教え子の数で評判が上下し、3月25日の査定で学年主任・教頭・校長へ昇進します（予算と指導ポイントの上限が増えます）。評判が低すぎると注意を受けます。
- 相談やお知らせ（期末試験の結果、査定、覚醒、レベルアップ）が来ると一時停止します（「教師」の画面で切り替え可能）。教師モードの記録は世界ごと（スロットごと）に保存されます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `js/core.js` | シード付き乱数、テンプレート展開、日付 |
| `js/data_*.js` | 名前・地名・能力・性格・事件文などの素材データ |
| `js/generator.js` | ヒーロー／ヴィラン／怪獣／組織／チームの生成 |
| `js/sim.js` | 1日ごとのシミュレーション本体 |
| `js/data_more.js` | 名前・能力・事件などの追加素材と、プロフィール用の素材 |
| `js/story.js` / `js/data_story.js` | 時代・黒幕・宿敵・事務所・全国大会などの長編の仕掛けと、その文面 |
| `js/drama.js` / `js/data_drama.js` | 連続事件・歴代記録・今週の注目・師弟やチームのドラマ・海外・治安ランキングと、その文面 |
| `js/academy.js` / `js/data_school.js` | ヒーロー養成校（生徒・行事・インターン・資格試験・卒業と進路）と、その文面 |
| `js/teacher.js` / `js/teacher2.js` / `js/data_teacher.js` | 教師モード（時間割・生徒の裏の数値・相談・絆・期末試験・予算と設備・教師の成長・査定）と、その文面 |
| `js/memory.js` / `js/data_memory.js` | 記憶と因果（雪辱・恩人・救われた子ども・命日）と物語の中心人物、その文面 |
| `js/arc.js` / `js/data_arc.js` | 連載の物語（数話で進むエピソードと、事件で決まる最終話）と、その文面 |
| `js/villain2.js` / `js/data_villain.js` | ヴィランの掘り下げ（プロフィール・懸賞金・目撃・対戦成績・語録・復讐・暗躍） |
| `js/data_names2.js` | 学園ものらしいヒーロー名の素材と組み立て |
| `js/ui.js` | 画面表示（号外・予想・目標・学園・担任・あらすじ・連載・相関図を含む） |
| `tools/headless.js` | Node で1年分を実行して統計を表示（`node tools/headless.js シード 年数`） |
| `tools/build.js` | 1ファイルのHTML（`dist/hero.html`）にまとめる |

素材を増やしたいときは `js/data_*.js` の配列に追記するだけで反映されます。事件文の `{h}` `{v}` `{loc}` などの差し込み記号と、`[A|B|C]`（ランダムに1つ選ぶ）が使えます。
